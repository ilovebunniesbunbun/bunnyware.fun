Read-Only External

Zero code injection and zero memory writes. State is ingested purely through Linux process_vm_readv, while visual overlays run in a completely isolated OpenGL context and input is dispatched via kernel evdev devices.

GPU-Skinned 3D Chams

Renders directly onto parsed VMDL player skeletal geometry with shaders for Metallic, Fresnel, Flat, and Pulsing styles with zero-allocation GL passes.

  • OpenGL 3.3 Compatibility Profile
  • Dynamic bone matrix interpolation
  • Customizable visible vs hidden shaders

Dual-Stage Occlusion Engine

Utilizes a GPU Depth Prepass rendering actual BSP/world geometry for pixel-perfect wall occlusion, with multi-threaded CPU BVH raytracing fallback.

  • GPU Depth buffer rendering
  • Multi-threaded CPU BVH raycaster
  • Automated map polygon caching

Legit Aim & Triggerbot

Natural mouse movement synthesis using progressive curve smoothing, FOV limits, dynamic recoil pitch/yaw compensation, and seed-aware hitchance verification.

  • Seed-aware weapon spread math
  • Capsule collision hitbox calculation
  • Target prediction & bone selection

Cloud Grenade Assistant

Synchronizes in real time with the cloud lineup database, providing trajectory arcs, landing indicators, and lineup assist for every map.

  • 1,000+ competitive grenade lineups
  • Bounce physics & detonation radius
  • Automated map lineup filtering

Movement & Strafe Trainer

Physics-aware movement automation: automated edge jump detection, auto-bunnyhop, and real-time counter-strafe efficiency tracking.

  • Automatic Edge Jump detection
  • CStrafe coach with gain % metrics
  • Competitive Auto-Accept matchmaker

evdev Input Emulation

All mouse and keyboard events are dispatched through /dev/input/event* (evdev).

  • Direct evdev driver emulation
  • No user-space input hooks or X11 fake events
  • Direct memory reads via process_vm_readv

Compiling from Source

Bunnyware compiles natively using standard CMake and modern C++20 compilers (GCC 10+ or Clang 11+).

Install all required dependencies, compilers, OpenGL, and Wayland libraries via pacman:

bash — install-deps-arch.sh
sudo pacman -S base-devel cmake pkgconf glfw-x11 glew glm spdlog \ wayland wayland-protocols mesa libx11 libxext nlohmann-json python-pytest libevdev

Install dependencies for Ubuntu 22.04+ or Debian 12+:

bash — install-deps-deb.sh
sudo apt update && sudo apt install -y build-essential cmake pkg-config \ libglfw3-dev libglew-dev libglm-dev libspdlog-dev libwayland-dev \ wayland-protocols libx11-dev libxext-dev nlohmann-json3-dev libevdev-dev python3-pytest

Clone the repository and compile using multi-threaded CMake:

bash — build.sh
# 1. Clone repository git clone https://github.com/ilovebunniesbunbun/bunnyware.git cd bunnyware # 2. Configure build environment cmake -B build -S . -DCMAKE_BUILD_TYPE=Release # 3. Compile binaries across all CPU cores make -j$(nproc) -C build

Launch live production mode (attaches directly to CS2) or offline shared memory simulation mode:

bash — run.sh
# Mode A: Production Live Mode (requires root / input group for evdev & memory reads) sudo ./build/bunnyware # Mode B: Offline Simulation / Test Mode (no root required) BUNNYWARE_SHM_NAME="/bunnyware_shm_bridge" ./build/bunnyware

Add this window rule to your hyprland.conf to make the overlay click-through, non-focus-stealing, and pinned on top:

hyprland.conf — windowrulev2
# Bunnyware Overlay Window Rules (Modern Hyprland v2) windowrulev2 = float, class:^(bunnyware.overlay)$ windowrulev2 = pin, class:^(bunnyware.overlay)$ windowrulev2 = size 100% 100%, class:^(bunnyware.overlay)$ windowrulev2 = move 0 0, class:^(bunnyware.overlay)$ windowrulev2 = nofocus, class:^(bunnyware.overlay)$ windowrulev2 = noblur, class:^(bunnyware.overlay)$ windowrulev2 = noshadow, class:^(bunnyware.overlay)$ windowrulev2 = noanim, class:^(bunnyware.overlay)$ windowrulev2 = borderwidth 0, class:^(bunnyware.overlay)$ windowrulev2 = suppressevent maximize, class:^(bunnyware.overlay)$

Prerequisites & Permissions

To run the binary directly, extract the tarball and launch with superuser permissions (or configure an input udev rule) so the engine can emit evdev hardware events and read process_vm_readv:

tar -xzf bunnyware-v2.0.0.tar.gz
sudo ./bunnyware

Tip: Open the ImGui menu with the INSERT key at any time to switch weapon profiles, tune smoothing curves, or adjust occlusion shaders.
